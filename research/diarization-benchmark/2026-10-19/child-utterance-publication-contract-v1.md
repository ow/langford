# Child utterance publication contract v1 — review only

Status: proposed read-only contract. No migration, publication, identity assignment, data update, or new model run is approved by this document.

Retain every parent transcript ID, original text, original start/end, and existing audit history unchanged. A recovered ASR text difference creates a distinct transcript version; it cannot masquerade as a split of the old paragraph. Bind each version to the actual parent row and its text hash, recording hash, raw ASR artifact hash, measured diarization hash, tokenizer configuration and installed decoding code hashes, time transforms, alignment version, and loaded alignment code hash. Validate artifact bytes and parent tuples before admission; a changed binding requires a new reviewed version.

A child has a stable version-scoped ID, parent ID, transcript version, ordinal, measured interval, exact original token indices, raw token text, anonymous speaker label, evidence receipt, and admission status. Preserve native sentence text separately from token concatenation. Hold all affected tokens when those disagree. Preserve boundary/context tokens and every unresolved lexical unit in the audit artifact. Never interpolate word times or cut an inseparable lexical unit across a measured voice boundary. Competing evidence includes the union of all other measured voices. Anonymous voice labels do not authorize person links.

Require an independent conservation check: every selected source token appears exactly once in an admitted child or a held unit, and selected plus context indices partition the raw ASR tokens. No held or conflicting unit enters publication. Parent history must retain the full source, holds, superseded versions, review decisions, and rollback target. Review decides whether a partial version with explicit gaps is publishable; the pilot grants no such decision.

Expose one active representation per parent/version in public reads. Selecting children suppresses the parent as an additional countable utterance; retain the parent as provenance and a navigation anchor. Aggregate speaking duration uses the union of admitted measured intervals, with no parent-plus-child double counting. Historical parent citations remain resolvable. Search and RAG must choose an active version consistently and deduplicate parent/child evidence. Do not produce embeddings per token or word: reuse an existing compatible parent embedding or schedule a separately reviewed semantic-chunk replacement, with one active searchable representation and version lineage.

Before publication, implement and independently verify a concrete migration and rollback plan, representative reader behavior, count reconciliation, source conservation proof, identity separation, and changed-artifact rejection. This pilot alone is not a publication receipt. Keep raw voice, transcript, identity leads, and local research artifacts in ignored private storage; public receipts contain aggregate counts, hashes, and limitations only.
