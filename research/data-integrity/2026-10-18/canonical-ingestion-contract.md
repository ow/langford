# Source-authoritative ordinary ingestion

The regular Langford Council, Committee of the Whole, and specifically validated Community Advisory Committee path now takes motions from native official formal decisions. Cached/model motions only enrich exact source words; omitted model motions remain in the source inventory, while invented proposals stay as agenda metadata. Unknown committees, missing/invalid native documents, and unbound dates hold rather than silently use model motions.

A canonical source identity binds meeting, binary SHA, native formal offset and source order. Unique exact legacy bodies or previously bound source keys retain motion primary keys and original agenda associations. Existing ballot rows are never deleted/reinserted during a document refresh. Source revisions with unchanged exact words retain the existing ID and keep previous keys plus eight nonrecursive native source-version snapshots. Changed critical identifiers/words without a unique proven legacy binding hold new insertion; unresolved legacy records block possible duplicate creation. Source surname actor IDs resolve only against the native PRESENT identities, never by creating a person from a surname.

Agenda records reuse unique exact order/title identities. Unmatched existing agenda records and key statements remain historical evidence. Exact repeated statement text is not appended again. Source-only motions without exact AI enrichment use a clearly named official-source agenda container rather than guessing agenda numbers from street addresses or numbered conditions. Existing motion enrichment is retained when the model omitted that source node. Planned-source refresh cannot downgrade an already occurred meeting. Dry runs load actual existing IDs and ballots without database mutations.

A source receipt is written `in_progress` before motion mutation, then `source_authoritative` only after the pass succeeds. Cached success requires the exact current binary hash; missing, changed, or interrupted receipts retry the source pass using cached refinement. Receipt counts include held source identities, unmapped old IDs and unbound native outcome-marker leads. These counts do not claim every outcome marker defines a motion.

Complete ballot metadata is staged as `named_only` / `vote_persistence_pending`; nested vote coverage is `pending`. After appending only missing choices, the worker rereads the exact full per-person ballot and verifies old vote IDs remain, then publishes the complete proof with a motion timestamp CAS. A mid-insert interruption therefore leaves partial evidence pending, never a complete public ballot. A source-key insert race rereads the exact conflicting key and retries against fresh motion/vote snapshots. The guarded partial unique index is required before concurrent operation; live preflight found no keyed legacy rows/duplicates, and the migration has not been applied by this lane.

The unique index was subsequently applied and its live unique/valid definition verified in `canonical-identity-index-applied-verification.json`; no motion or vote data rows changed. The REST sequence is not a database transaction. A direct unrelated writer changing votes alone after the final reread could still race proof publication; a transactional RPC would remove that last inter-request window. Existing source validators remain strict for policy/roster/quorum/identity/presence/choice conflicts. COTW/CAC results remain recommendations/guidance; no inferred membership intervals are created from CAC attendance.

Source coverage v2 uses the same production parser: 344 source entries, 4,660 extracted formal decisions (4,615 moved, 45 resumed main), 4,697 outcome markers and 37 unbound leads, with four source inventory errors. The frozen original 113-mapping inputs/reviews remain unchanged. This is a parser inventory, not universal completeness certification. OCR-damaged names/dates, formal attempts without seconders, bodies printed before the mover, other unfamiliar markers and ambiguous legacy paraphrases need further machine source reconciliation; none authorize invented motions, votes or outcomes.
