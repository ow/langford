# Local original-header date recovery

`native_header_ocr.py` is the last date fallback for an original PDF when the ordinary native header has no valid date. It changes only the source date and its provenance. Motion words, source text, names, rosters, attendance, transcripts, policies and summaries remain untouched.

The helper reopens page one, requires one native `PRESENT` word with a plausible bounding box, and renders the full page width strictly above that word at 6x. A missing/ambiguous anchor holds. Thus cleaner dates in adopted prior minutes or later agenda items cannot substitute for this meeting's own header.

Apple Vision runs locally through the checked-in Swift asset. Each date-bearing header line must have a confidence-1 **top** candidate with one grammatical full English month/day/year date. An ordinal, if present, must match its day. A printed weekday must match the recovered date. Other complete confidence-1 alternatives must agree; an invalid top is never replaced with a convenient lower candidate. Only after independent recovery is the catalogue date compared (at most one day difference). No day digit is borrowed from the catalogue, filename or body. A malformed `215`/`21s` stays held.

The source hash, helper hash, macOS version, machine architecture, Vision revision/configuration, PyMuPDF version, exact render clip/scale and rendered PNG hash bind the local cache. Raw OCR alternatives, bounding boxes and engine revision remain in its hashed receipt; accepted source evidence points to the receipt and render. A changed source hash during extraction holds. No macOS/Swift, unavailable Vision, malformed output, subprocess error or bounded timeout holds rather than guessing.

The compiled helper uses a stable `langford-native-ocr` executable basename inside a helper-hash directory. On the current macOS27 host, changing the executable identity caused cold Neural Engine model compilation to stall; the stable identity allows the legitimate local model cache to survive source/helper cache directory changes. The binary is still freshly compiled from the hash-bound checked-in asset; the research executable is never copied into production. Compilation is bounded to60seconds and recognition to40seconds. A genuinely cold/unavailable machine can hold and retry.

Evidence: the real original2019-04-01 first-page loader regression failed before the fallback (`None` instead of2019-04-01), then passed with actual local Vision. The original2016-11-21 page remains held because its confidence-1 top reading is `November215`, despite visually legible printed21st. Fixtures retain the original corrupt native text layer and are documented by source URL/original and fixture hashes in `tests/fixtures/native-headers/provenance.json`.

The combined owner suite passed137 tests, followed by2 native-header cases after the final loader source-hash guard. `native-header-production-replay.json` records an actual production-helper replay of10 original sources:9 dates recovered, covering31 of42 date-held decisions; the remaining11 all belong to the malformed November21 ordinal source. Date recovery alone certifies no ballot. No database writes or paid model calls occurred.
