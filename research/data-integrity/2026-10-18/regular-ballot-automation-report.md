# Regular workflow ballot automation

Production paths: `pipeline/ingestion/official_ballots.py`, `meeting_ballots.py`, `policies/langford-voting.json`, and narrow `ingester.py` hooks. No model output proves an inferred ballot. Original native PDF/structural HTML, an exact unique formal motion, outcome, original roster, per-vote physical presence and dated Council memberships must all agree.

Each ordinary document ingestion loads source and membership inventory once, automatically checks the official bylaw directory and exact bylaw content hash, then validates every motion. Unchanged policy extends the verified date range automatically; changed/unavailable policy holds inference for machine reevaluation. There is no additional AI request or recurring human approval per meeting. Costs are two official HTTP checks per meeting, local native parsing and database reads. Poppler `pdftotext` is required for original PDFs; validated structural official HTML is supported separately.

Council and separately documented Committee of the Whole scope are supported for Langford. COTW requires native header/catalog agreement and the reviewed original/current bylaw scope; proof labels its outcome guidance/recommendation rather than final Council adoption. Other committees remain held. Unknown roster identities, missing dated membership inventory, ambiguous movements/recusals, uncertain initial attendance, changed policy, nonexact/ambiguous motion bodies, conflicting votes/outcomes or special thresholds stay partial and excluded from alignment.

Complete proof stores source URL/SHA/body/date, roster/events, scope, exact per-person choices/quotes and compact `choice_provenance`. Inferred choices remain distinct from explicitly named votes; explicit unanimity has its own method. A current conflict never overwrites an old choice or inherits a complete alignment badge. All held coverage is `named_only`, with old proof preserved separately.

During item refresh, voted old motions must map uniquely to exact unchanged new bodies before destructive writes. Unmappable/duplicate bodies stop the refresh. Successful refresh still recreates motion IDs: this patch does not redesign motion identity/upsert. Existing transcript rows/IDs/person assignments remain unchanged during document refresh.

The original parity pass matched all 826 then-eligible frozen ballots exactly before independent review added stricter membership/source-body gates. The shared audit now routes through this same production validator. The final owner suite passed 73 tests, covering ordinary complete persistence, prior-choice conflicts, stale alignment coverage, native scope, COTW recommendations, automatic policy refresh, source recovery, transcript preservation and worker failure propagation. Missing-membership and mislabeled-native-committee cases reproduced unsafe acceptance before repair. This integration itself performed no live vote writes; controlled batch audits/apply remain in the vote lane.
